# Code of conduct

Compass follows the Contributor Covenant, version 2.1:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

It applies in every project space: issues, pull requests, discussions and
reviews, and anywhere someone represents the project.

## Reporting

Report conduct that breaks it to conduct@ayeo.io. The maintainer reads every
report, keeps the reporter's identity private, and replies.

Enforcement follows the Covenant's enforcement guidelines: a correction, a
warning, a temporary ban or a permanent ban, depending on the conduct.
