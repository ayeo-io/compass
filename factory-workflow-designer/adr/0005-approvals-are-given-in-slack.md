# Approvals are given in Slack, not with GitHub labels

The Workflow Bot asks for each Approval in a Slack thread, and the Owner gives it by replying there with a mention of the Bot. A GitHub label cannot carry an Approval: the Bot works on GitHub as the Owner, so a label it applies looks the same as one the Owner applied, and the Owner's own label never starts the Bot's automations. In Slack the Bot posts as itself, so the Owner's reply can be told apart from it, and the mention starts a Workflow Run at once. The Coordinator records each Approval on the pull request as a comment that links the Slack message. A GitHub label stays as a fallback for teams without Slack, and the Bundle warns that such an Approval cannot be verified. That a Slack mention from the Bot's own Owner starts its automation is expected from Orca's docs but not yet tested; milestone 3 checks it first.
